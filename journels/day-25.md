# DAY-25
Today i worked on two important things in DragonIDE! I added the Quick open feature using `Ctrl + P`, so we can search files by name and open them quickly. I also improved the search panel to show matching file names.

The Second thing was the terminal. I worked on live output, the stop button, `Ctrl + C` to stop running commands, `cd` support, command
history using arrow keys, and showing errors with exit codes.

Finding bugs and reserching how to fix everthing took a lot of time. I tested the Rust code and js seperately before planning the changes. Some problems were tricky, especially handling terminal output and stopping running processes.

This work took around 3 hours of debugging, research, and improvements. Still more things to build, but DragonIDE is slowly getting better! 🦊
